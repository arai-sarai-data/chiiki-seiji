# 住所から見る 地域の政治とお金

住所を入れると、あなたの選挙区と、その地域から選ばれた国会議員の名前・政党、会派ごとの議案への賛否、選挙の得票を表示します。数字はすべて公開データから。出典リンクつき。

**サイト：** https://arai-sarai-data.github.io/chiiki-seiji/

- 日本語・English・中文・한국어 に対応（`?lang=en` などで切り替え）。
- 数字はすべて公的機関の公開データから計算しています。出典は各ページに書いています。
- 誤りの訂正・削除のご連絡：arai-sarai-data@proton.me（該当ページのURLと原本の該当箇所を添えてください）
